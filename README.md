# AI Image Detector 

An advanced Machine Learning web application designed to identify whether an image is generated by Artificial Intelligence or captured in the real world. 

## Features
* **AI-Powered Detection:** Utilizes a custom Convolutional Neural Network (CNN) built with TensorFlow/Keras.
* **Instant Analysis:** Fast and responsive web interface built with Flask.
* **Confidence Scoring:** Provides a percentage indicating the reliability of the model's prediction.

## Tech Stack
* **Backend:** Python, Flask
* **Machine Learning:** TensorFlow, Keras, NumPy
* **Frontend:** HTML, CSS
